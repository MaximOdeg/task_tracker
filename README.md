# Описание 
Необходимо реализовать серверное приложение для работы с базой данных, представляющее собой трекер задач сотрудников. Приложение должно обеспечивать CRUD операции для сотрудников и задач, а также предоставлять два специальных эндпоинта для получения информации о загруженности сотрудников и важных задачах.

# Установка

1. Клонировать репозиторий.
https://github.com/MaximOdeg/task_tracker.git
2. Применить все зависимости с файла requirements.txt
pip install -r requirements.txt
3. Создать файл .env и внести все чувствительные параметры указанные в файле .env.sample
4. Для запуска приложения в Docker используйте следующие команды:
docker-compose up -d --build
Остановка:
docker compose down

# Тестирование
Запуск тестов:

pip install pytest pytest-cov
pytest --cov=app tests/

В проекте реализованы тесты на весь функционал проекта с покрытием в 92%
